왜 휴대폰에서 계산하나요?

사용자가 늘어도 서버 부담이 없고, 경로의 출발·도착 위치를 서버로 보내지 않습니다. (주변 찾기만 현재 위치로 검색하고 저장하지 않음)

점검

기능 점검 8종(npm test) + 실제 사이트를 휴대폰 크기로 자동 조작하는 16단계 점검(npm run check:live)

지역 좌표만 정하면 같은 스크립트로 데이터를 다시 만듭니다 (전주 → 군산 · 제주 추가)
